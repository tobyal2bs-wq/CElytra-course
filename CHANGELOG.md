# Changelog

## [1.2.1] - 2026-11-07

First public release in `tobyal2bs-wq/CElytra-course`. The plugin's Bukkit name remains **CircleCheckpoints**, preserving its commands and data-folder path.

- Compact 7-block XP-orb rings with independent named courses and ordered checkpoints.
- Live checkpoint count and millisecond timer in the action bar.
- Fastest-time leaderboards, personal bests, and `%elytra%` / `%elytra_1%` through `%elytra_100%` placeholders.
- Axiom-editable center display handles and arbitrary three-axis ring rotation.
- Soft XP pickup sounds for accepted checkpoints and damage-protected green-and-gold finish fireworks.
- Paper 26.2 / Paper-compatible fork and Folia scheduler support; Java 25 required.
- PacketEvents 2.14+ required; PlaceholderAPI required for placeholders.

Validation: 39 local automated tests and the plugin-layout check passed. Live server/client, individual-fork, Axiom, and hologram integration remain unverified.
